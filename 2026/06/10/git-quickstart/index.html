6. .gitignore 的使用

6.1 什么是 .gitignore？

在项目根目录创建一个 .gitignore 文件，写入不需要 git 跟踪的文件或目录模式，git 会自动忽略它们。

6.2 文件已被跟踪后再加入 .gitignore 怎么办？

.gitignore 只对未跟踪（untracked）的文件有效。 如果一个文件在加入 .gitignore 之前就已经被 git add 或 git commit 跟踪了，那么 .gitignore 对它无效，git 会继续追踪它的变更。

7. 注意事项

  • 先 pull 再 push：推送前先 git pull，避免冲突
  • 写清晰的 commit message：简明扼要说明本次提交做了什么
  • 不要提交敏感信息：密码、密钥等不要提交到 git
  • 及时提交：完成一个功能点就提交一次，不要攒一大堆再提交
