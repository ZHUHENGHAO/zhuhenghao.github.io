RagChat机器人项目

写于：2026-05-14

项目背景

在飞速发展的时代，每个公司或多或少都沉淀出了自己公司体系的一些操作手册或是说明文档，这些文档的体现形式可能是企业级wiki、公司所属PC的本地文档，然而当这些文档的体系过于庞大，如何去找到想要的某个知识点就十分繁琐，传统的方法可能就只能去进行文档标题的搜索，往往一个文档的标题无法涵盖其文档内容的所有知识点，且需要进行此知识点进行搜索的同事本身对其的概念就比较模糊，想要得到想要的答案会非常麻烦，很影响整个开发和对接的效率。恰逢AI盛行的时代，我们可以利用好LLM与用户实时对话的特点，开发一个对话机器人。这个对话机器人的核心是一个包含知识库的大模型，于是有了RagChat这个项目。它的存在对于通过wiki或内部文档查找知识点繁琐、麻烦、不准确的问题就十分必要了，简单来说，我们可以基于现有的wiki或是文档通过RAG进行切片、向量化等，完成知识库的搭建，再接入大模型，在同事使用大模型提问时，会优先从这个知识库里去检索并回答，从而更快、更准的回答同事的问题。

项目简介

这是一个面向知识检索与对话场景的 RagChat 机器人项目，目标是把知识库检索与大模型对话结合起来，形成可落地的问答，同事无需再去wiki一个一个文档的搜索查找答案，而是通过与RagChat对话得到答案和相应wiki对应的目录。本文先搭一个可更新的框架，后续补充实现细节与效果评测。

核心目标

  • 抓取指定wiki及其子目录下的所有信息并完成文档转换、合并、格式纠错
  • 将转换好的文档快速接入本地/云端知识库，提升回答准确度
  • 支持多轮对话与上下文追踪

系统结构

1：知识库构建与更新流程（文档入库）

  • 从企业 Wiki（Confluence）拉取指定目录内容，通过接口获取页面 HTML
  • 本地完成格式清洗与转换（如 md/PDF / JSON），进入批量入库流程
  • 调用 RAGFlow 的数据集查询接口，获取目标数据集 ds_abc
  • 上传文档到数据集，并触发解析任务
  • RAGFlow 进行 OCR / 切片 / 向量化，写入磁盘与向量库
  • 轮询解析状态，直到文档切片完成并可检索

2：问答检索与生成流程（在线对话）

  • 同事提出问题，RagChat 机器人接收请求
  • RagChat 调用 RAGFlow 检索接口，将问题向量化并搜索数据集
  • 返回 top-5 相关文档片段（chunks）作为上下文
  • RagChat 组装 prompt = 问题 + chunks发送给 LLM
  • LLM 生成回答，RagChat 返回答案并附带引用来源

本人负责部分

  • 完成数据样例与索引方案说明
  • 完成wiki的抓取、文档纠错整合、rag知识库的更新与上传
  • 补充评测指标与效果对比
